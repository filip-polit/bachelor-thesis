# bachelor-thesis

Model used for BSc Thesis (Differential VAT In Denmark: An Efficiency Analysis) by Sigurd Dybbro Ring and Filip Budny

Purpose of files is as follows.

Model

- full_model.py includes the three equillibriums, parameters and the construction of the income tax schedule

Figures
- baseline_equillibrium_table.py creates a latex table with state 0 equillibrium allocations

- main_results_seperable.py creates a latex table with main results (table 3)

- various_reforms.py creates a plot over reform simulations across a reform space (figure 2)
